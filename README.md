# 🛒 סל חכם – באר שבע, נס ציונה, ראש העין

אפליקציה להשוואת מחירי סל קניות בין הסופרים בבאר שבע, לפי קבצי המחירים שהרשתות מחויבות לפרסם (חוק קידום התחרות בענף המזון).

- **האתר:** נבנה אוטומטית ל-GitHub Pages. כל ההשוואה רצה בדפדפן – אין שרת.
- **עדכון מחירים:** כל בוקר GitHub Actions מוריד את המחירים ומפרסם מחדש (`.github/workflows/update.yml`). אפשר גם ידנית: Actions → "עדכון מחירים ופרסום האתר" → Run workflow.
- **מילון מוצרים:** `app/items.json` – איך כל מוצר מזוהה ובאיזו כמות משווים.

| תיקייה | מה יש בה |
|---|---|
| `site/` | האתר: `index.html` (ממשק) + `engine.js` (מנוע ההשוואה) |
| `app/` | קוד ההורדה והניתוח (Python) |
| `tools/build_data.py` | הורדה + ייצוא ל-`site/data/prices.json` |
| `geo.json` | מיקומי הסניפים שאותרו (מתעדכן אוטומטית) |
| `seed/prices.json` | נתוני התחלה, לגיבוי אם ההורדה הראשונה נכשלת |
